# DESIGN.md — KJÁR

Решения приняты до кода. Любое значение цвета, кегля, радиуса или отступа вне этого
файла считается багом.

Проект: сайт ролевой игры по картам персонажей. Скандинавский север, туман, кора,
руническая метка на дереве. Аудитория — игроки, которые читают длинные тексты лора
и следят за ивентами.

---

## Палитра

Шесть значений плюс один системный цвет ошибки.

Палитра «лес». Поверхности почти нейтральные, зелень держится только в акценте и на
плашке имени: сплошной зелёный фон делал сайт болотным.

```
--bark    #171916   фон, холодный уголь
--peat    #1f211d   поверхность карточки
--line    #2c2e28   границы и линейки
--moss    #475248   светлая зелёная плашка
--plate   #2a3426   плашка имени на карте персонажа, базовый оттенок палитры
--ash     #9b9d93   второстепенный текст, подписи, проза
--ink     #e7e8e2   заголовки и основной текст
--gold    #a3b592   единственный акцент: действие, активное состояние, ссылка
--rust    #cc6a48   только ошибка формы
```

Контраст (посчитан, не на глаз): `--ink` на `--bark` 14.5:1, `--ash` на `--bark` 6.5:1,
`--ash` на `--peat` 6.0:1, `--gold` на `--bark` 8.2:1, `--ink` на `--plate` 10.5:1.
Все проходят WCAG AA для основного текста.

Служебное значение `--ash-on-line` (#a4a69c) существует только для текста на плашке
`--line`.

Запрещено: градиенты, тени, второй акцент, чистые `#fff` и `#000`
в тексте и фонах. Чёрный `#000` используется ровно в одном месте — пустое
изображение, где он читается как отсутствие карточки, а не как цвет.
Свечение допускается ровно одно: подсветка рамки карты персонажа под курсором.

## Типографика

```
rune:    Norse 400/700 — вордмарк, навигация, заголовки, плашка имени на карте
display: Alegreya 500/700, прямое начертание — заголовки карточек, цифры сводки
body:    Golos Text 400/500/600 — текст, интерфейс, подписи
```

Norse (кириллическая версия) даёт резаные, «вырубленные» формы северных надписей.
Она работает только на коротких строках: вордмарк, пункты меню, заголовки, имя на карте.

Alegreya — антиква с рукописным происхождением букв, для длинных саговых текстов.
Golos Text — русский гротеск Паратайпа с родной кириллицей, а не латинская гарнитура
с достроенной кириллицей.

Шкала, px: **13 / 16 / 20 / 28 / 44 / 72**. Промежуточных значений нет.

```
--t-xs   0.8125rem  13px  подписи, даты, метки
--t-s    1rem       16px  текст, интерфейс
--t-m    1.25rem    20px  заголовок карточки, подзаголовок
--t-l    1.75rem    28px  заголовок секции
--t-xl   2.75rem    44px  заголовок страницы
--t-2xl  4.5rem     72px  заголовок героя (clamp от 44)
```

Курсив только в одном месте — короткая характеристика персонажа под именем.
В заголовках курсива нет.

## Форма

```
Радиусы:  0 (орнамент, полосы) / 4 (поля, кнопки, метки) / 10 (карточки)
Отступы:  4 / 8 / 16 / 32 / 64 / 128
Тени:     не используются
```

Иерархия строится пространством и линейками. Рамку получают только объекты, которые
пользователь воспринимает как отдельную сущность: карта персонажа, пост, ивент, тема,
форма. Панели, сводки, боковые блоки и списки рамок не имеют.

Вложенность контейнеров — максимум один уровень. Этапы ивента, поля фильтров и
пустые состояния внутри блоков разделяются линейками, а не своими рамками.

## Signature

**Карта персонажа как физический объект: портрет 3/4 во всю ширину карточки, метка роли
поверх портрета, под линейкой имя и характеристики.** Колода собирается в сетке карт,
а не в декоре. Это единственный громкий приём.

Герой при этом чисто типографический: заголовок, абзац, два действия и фотография леса
на фоне. Никаких объектов справа.

Второй мотив, тканый северный орнамент, работает строго как разделитель в двух местах
(под героем и над подвалом) и нигде больше.

## Тест на дефолт

Пришёл бы я к этому же для брифа другой отрасли? Нет:

- карточка персонажа с портретом и характеристиками выведена из механики самой игры,
  для клиники или SaaS она бессмысленна;
- Alegreya выбрана под длинные тексты лора, а не под «современный лендинг»;
- пустое изображение показывается чёрным прямоугольником, потому что мир игры тёмный,
  и отсутствие портрета честнее серой заглушки с горами;
- орнамент взят из северного ткачества, а не из библиотеки декоративных разделителей.

## Движение

Анимации на сайте нет. Интерфейс меняет только цвет за 0.15s: ссылка, карточка под
курсором, поле в фокусе. Всё под `prefers-reduced-motion`.

## Ссылки

Три роли, три вида:

- **действие** («Войти в ивент», «Все посты», «К списку статей») — золотое, полужирное,
  со стрелкой направления, подчёркивание при наведении;
- **объект** (заголовок карточки, строка списка) — цвет текста, золотеет при наведении;
- **навигация** (меню, подвал) — приглушённая, золотеет при наведении.

Стрелка кодирует направление перехода и ставится только у действий.

## Копирайтинг

- Тире не больше одного на абзац, вставные конструкции переписываются запятыми или скобками.
- Кнопка называет результат: «Опубликовать комментарий», а не «Отправить».
- Пустое состояние приглашает к действию и даёт ссылку, а не сообщает о пустоте.
- Sentence case везде. Капс только в вордмарке `KJÁR`.
